# 📍 Postal Code Genesis Platform

> **Building Addresses Where None Exist** — A complete platform for creating postal code systems in developing nations.

## Architecture

| Layer | Technology |
|-------|-----------|
| Database | PostgreSQL + PostGIS |
| API | FastAPI (Python 3.11) |
| Frontend | React 18 |
| Maps | Google Maps SDK / Leaflet fallback |
| Deployment | Docker Compose · Render.com |

## Quick Start (Docker Compose)

```bash
cd postal-code-genesis

# Set Google Maps key (optional)
export GOOGLE_MAPS_API_KEY=your_key_here

# Start all services
docker compose up --build

# Seed demo data (South Sudan)
docker compose exec backend python scripts/seed_demo.py
```

| Service | URL |
|---------|-----|
| Frontend | http://localhost:3000 |
| Backend API | http://localhost:8000 |
| API Docs | http://localhost:8000/docs |
| Database | localhost:5432 |

## Deploy on Render

The project includes a `render.yaml` blueprint that deploys two services:

1. **postal-genesis-db** — Private PostGIS database
2. **postal-genesis** — Combined backend + frontend web service

### Steps

1. Push this repo to GitHub
2. Go to [dashboard.render.com](https://dashboard.render.com) → **New** → **Blueprint**
3. Select the repo — Render creates both services from `render.yaml`
4. Set `GOOGLE_MAPS_API_KEY` in the web service env vars (optional)
5. Click **Apply** — done!

After deploy, your app is live at `https://postal-genesis-xxxx.onrender.com`

### How it works on Render

- `Dockerfile.render` is a multi-stage build: React frontend → Python backend
- The built React app is served by FastAPI as static files (no separate frontend service)
- The PostGIS database runs as a private service; the backend connects via `DB_HOST`/`DB_PORT` env vars
- `POSTGRES_PASSWORD` is auto-generated by Render

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/v1/countries` | Create country profile |
| GET | `/api/v1/countries` | List all countries |
| POST | `/api/v1/countries/{id}/analyze` | Analyze & get recommendations |
| POST | `/api/v1/countries/{id}/zones/auto-create` | Auto-generate postal zones |
| GET | `/api/v1/countries/{id}/zones` | List all zones |
| GET | `/api/v1/countries/{id}/stats` | Country statistics |
| POST | `/api/v1/countries/{id}/policy` | Generate policy documents |
| GET | `/api/v1/lookup/coordinates` | Lookup by GPS |
| GET | `/api/v1/lookup/search` | Search by name/landmark |
| POST | `/api/v1/lookup/ussd` | USSD/SMS lookup |
| GET | `/health` | Health check |
